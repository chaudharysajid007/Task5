# Task 05: Common JavaScript Properties to Get Values from HTML
 
## 📌 About the Project
 
This project demonstrates common JavaScript properties used to access values, text, HTML content, and attributes from HTML elements. It includes interactive examples to help beginners understand how JavaScript interacts with the DOM (Document Object Model).
 
## 🚀 Properties Covered
 
1. `.value` — Gets the current value of a form element.
2. `.innerText` — Gets the visible text of an element.
3. `.textContent` — Gets the text content of an element.
4. `.innerHTML` — Gets the HTML markup inside an element.
5. `.outerHTML` — Gets the element itself, including its HTML markup.
6. `.checked` — Checks whether a checkbox or radio button is selected.
7. `.selectedIndex` — Gets the index of the selected dropdown option.
8. `.files` — Accesses files selected through a file input.
9. `.className` — Gets the CSS class names of an element.
10. `.id` — Gets the ID of an element.
11. `.attributes` — Accesses the HTML attributes of an element.
